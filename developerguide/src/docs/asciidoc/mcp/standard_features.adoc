[[standard_features]]
== 標準提供機能

[[standard_features_metadata_crud]]
=== メタデータCRUD

メタデータの操作（作成、読み取り、更新、削除）を行うための機能を、MCP Tool として提供します。

メタデータCRUD機能は、WebAPI のメタデータCRUDで利用しているコマンドを MCP Tool として提供するものです。 +
メタデータCRUD機能を利用するには、以下の設定が必要となります。

* WebApiService の `enableDefinitionApi` プロパティの設定を行う必要があります。 +
詳細については、 link:../../serviceconfig/index.html#WebApiService[Configuration - WebApiService^] を参照してください。
* ツールを実行する利用者は、管理者としての権限が必要です。

[NOTE]
====
メタデータCRUD機能は、開発時の利用を想定した機能です。
====

[[standard_features_entity_crud]]
=== EntityデータCRUD

Entityデータの操作（検索、登録、更新、削除）を行うための機能を、MCP Tool として提供します。

EntityデータCRUD機能を利用するには、以下の設定が必要となります。

* 操作対象の Entity に対して、EntityWebApi定義で該当する操作を許可する必要があります。操作の種別は INSERT、SELECT（Load）、SELECT（Query）、UPDATE、DELETE です。 +
詳細については、link:../webapi/index.html#entity_crud_api_permission[WebAPI - Entity CRUD API - 権限設定^] を参照してください。
* データの操作は、ツールを実行する利用者の権限で行われます。利用者には、操作対象の Entity に対する Entity権限が必要です。 +
詳細については、link:../authorization/index.html#en_entityperm[認可 - 権限管理 - Entity権限^] を参照してください。


[[standard_features_entity_crud_getEntity]]
==== Entityデータ検索

Entityデータを検索またはロードする機能です。 +
パラメータの組み合わせにより、以下の 3 パターンの処理を実行します。

[cols="1,2,3", options="header"]
|===
| パターン
| 指定するパラメータ
| 処理

| EQL検索
| query
| 指定された EQL を実行します。

| Entity指定検索
| definitionName、filter（任意）
| 指定された Entity のデータを filter の条件で検索し、全プロパティを取得します。

| ロード
| definitionName、oid、version（任意）
| oid で指定された単一の Entityデータをロードします。
|===

query と definitionName は、いずれか一方を必ず指定します。同時には指定できません。

.ツール名
getEntity

.パラメータ
[cols="1,3", options="header"]
|===
| 項目
| 説明

| query
| 検索する EQL を設定します。

| definitionName
| 検索またはロードする Entity の定義名を設定します。

| filter
| definitionName で指定した Entity に対する Where句の条件式を設定します。 +
definitionName による検索時のみ有効です。

| oid
| ロードする Entityデータの oid を設定します。definitionName と組み合わせて指定します。

| version
| ロードする Entityデータのバージョンを設定します。oid と組み合わせて指定します。 +
oid を指定せずに version のみを設定した場合はエラーとなります。

| countTotal
| true または false を設定します。true が設定された場合、検索条件に該当するデータの総件数を取得します。検索時のみ有効です。

| withMappedByReference
| true または false を設定します。true が設定された場合、参照プロパティのうち被参照プロパティも取得します。 +
definitionName による検索およびロード時に有効です。未指定時のデフォルト値は link:../../serviceconfig/index.html#EntityWebApiService[Configuration - EntityWebApiService^] で設定します。
|===

.レスポンス
[cols="1,3", options="header"]
|===
| 項目
| 説明

| status
| ツールの実行結果を表します。成功した場合は "SUCCESS" を返却します。

| list
| 検索結果の Entityデータの配列が返ります。 +
ロードの場合も、ロードした Entityデータを 1 件含む配列が返ります。該当するデータが存在しない場合は空の配列が返ります。

| count
| countTotal に true を設定した場合に、検索条件に該当するデータの総件数が返ります。
|===

[NOTE]
====
検索で取得できる件数には上限があります。上限件数は link:../../serviceconfig/index.html#EntityWebApiService[Configuration - EntityWebApiService^] の `maxLimit` で設定します。 +
EQL に limit句が指定されていない場合、検索結果は上限件数までに切り詰められます。ただし、`throwSearchResultLimitExceededException` が true の場合は、該当件数が上限を超えるとエラーとなります。 +
上限を超える件数の limit句を指定した場合もエラーとなります。 +
上限を超える件数のデータを取得する場合は、query による検索を利用し、EQL の limit句と offset句でページングして分割取得してください。definitionName による検索では limit を指定できないため、取得できる件数は常に上限件数までとなります。
====


[[standard_features_entity_crud_createEntity]]
==== Entityデータ登録

Entityデータを新規に登録する機能です。 +
指定された Entity にデータを登録し、登録したデータの oid を返却します。

.ツール名
createEntity

.パラメータ
[cols="1,3", options="header"]
|===
| 項目
| 説明

| definitionName
| 登録する Entity の定義名を設定します。必須項目です。

| entity
| 登録する Entityデータを、プロパティ名をキーとするJSONオブジェクトで設定します。必須項目です。 +
JSONオブジェクトには、definitionName パラメータと同じ値の `definitionName` を含める必要があります。
|===

.レスポンス
[cols="1,3", options="header"]
|===
| 項目
| 説明

| status
| ツールの実行結果を表します。成功した場合は "SUCCESS" を返却します。

| oid
| 登録した Entityデータの oid が返ります。
|===

.entity パラメータの設定例
[source,json]
----
{
  "definitionName": "sample.Product",
  "name": "商品A",
  "price": 1000,
  "category": {"definitionName": "sample.Category", "oid": "1001"}
}
----


[[standard_features_entity_crud_updateEntity]]
==== Entityデータ更新

Entityデータを更新する機能です。 +
oid で指定された Entityデータを更新し、更新したデータの oid を返却します。バージョン管理している Entity の場合は、更新後のバージョンも返却します。

.ツール名
updateEntity

.パラメータ
[cols="1,3", options="header"]
|===
| 項目
| 説明

| definitionName
| 更新する Entity の定義名を設定します。必須項目です。

| oid
| 更新する Entityデータの oid を設定します。必須項目です。

| version
| 更新対象のバージョンを設定します。バージョン管理している Entity の場合に有効です。 +
`-1` を設定した場合は、新しいバージョンのデータとして登録します。未指定の場合は、現在有効なバージョンのデータを更新します。

| entity
| 更新内容を、プロパティ名をキーとするJSONオブジェクトで設定します。必須項目です。 +
JSONオブジェクトには、definitionName パラメータと同じ値の `definitionName` を含める必要があります。 +
JSONオブジェクトに含めたプロパティのみが更新対象となります。 +
`updateDate` に更新前の更新日時を含めた場合、更新時にタイムスタンプチェックが行われ、更新日時が一致しない場合はエラーとなります。
|===

.レスポンス
[cols="1,3", options="header"]
|===
| 項目
| 説明

| status
| ツールの実行結果を表します。成功した場合は "SUCCESS" を返却します。

| oid
| 更新した Entityデータの oid が返ります。

| version
| バージョン管理している Entity の場合に、更新後のバージョンが返ります。
|===

[[standard_features_entity_crud_recommendation]]
==== 利用にあたっての推奨事項

Entity およびプロパティの表示名（displayName）と説明（description）を十分に記述することを推奨します。 +
LLM が対象の Entity やプロパティを正しく特定し、意図した通りにデータを操作するための手がかりとなるためです。

各ツールの説明文では、プロパティ定義の確認に <<standard_features_metadata_crud_getDefinition>> を利用するよう LLM に案内しています。 +
名前だけでは意味や取りうる値が伝わらないプロパティ（コード値、フラグ、単位を持つ数値など）には、説明に意味と設定可能な値を記述してください。

NOTE: <<standard_features_metadata_crud_getDefinition>> の利用には、<<standard_features_metadata_crud>> に記載の設定と管理者権限が必要です。
