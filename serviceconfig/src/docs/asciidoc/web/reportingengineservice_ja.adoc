[[ReportingEngineService]]
=== ReportingEngineService
帳票出力を管理するサービスです。

==== インタフェース名
----
org.iplass.mtp.impl.report.ReportingEngineService
----

==== 実装クラス名
----
org.iplass.mtp.impl.report.ReportingEngineServiceImpl
----

==== ReportingEngineServiceの設定
ReportingEngineServiceを設定します。

===== 設定項目
[cols="1,1,3", options="header"]
|===
| 項目 | 値 | 説明
| reportingEngine | <<ReportingEngine>>、複数指定可 | 帳票出力エンジンの設定。
|===

[[ReportingEngine]]
.ReportingEngine
classにorg.iplass.mtp.impl.report.ReportingEngineの実装クラスを指定します。

標準で以下のReportingEngineを提供します。

* <<JasperReportingEngine>>
* <<PoiReportingEngine>>
* <<JxlsReportingEngine>>

[[JasperReportingEngine]]
.JasperReportingEngine
Jasper Reportを利用して帳票を作成するためのエンジンです。

classはorg.iplass.mtp.impl.report.JasperReportingEngineを指定します。
以下の項目を設定可能です。
[cols="1,1,3", options="header"]
|===
| 項目 | 値 | 説明
| supportFiles | String、複数指定可 |サポート対象のファイル形式。
|===

[[PoiReportingEngine]]
.PoiReportingEngine
Apache POIを利用して帳票を作成するためのエンジンです。

classはorg.iplass.mtp.impl.report.PoiReportingEngineを指定します。
以下の項目を設定可能です。
[cols="1,1,3", options="header"]
|===
| 項目 | 値 | 説明
| supportFiles | String、複数指定可 |サポート対象のファイル形式。
|===

[[JxlsReportingEngine]]
.JxlsReportingEngine
JXLSを利用して帳票を作成するためのエンジンです。

classはorg.iplass.mtp.impl.report.JxlsReportingEngineを指定します。
以下の項目を設定可能です。
[cols="1,1,3", options="header"]
|===
| 項目 | 値 | 説明
| supportFiles | String、複数指定可 |サポート対象のファイル形式。PDF_JXLSを指定した場合は、PDF変換サービス（<<PdfConversionService>>）を利用してPDFを出力します。
|===

===== 設定例
[source,xml]
----
<service>
	<interface>org.iplass.mtp.impl.report.ReportingEngineService</interface>
	<class>org.iplass.mtp.impl.report.ReportingEngineServiceImpl</class>
	<property name="repotingEngine" class="org.iplass.mtp.impl.report.JasperReportingEngine">
		<property name="supportFiles" value="PDF"/>
		<property name="supportFiles" value="XLS"/>
		<property name="supportFiles" value="XLSX"/>
	</property>
	<property name="repotingEngine" class="org.iplass.mtp.impl.report.PoiReportingEngine">
		<property name="supportFiles" value="XLS_POI"/>
		<property name="supportFiles" value="XLSX_POI"/>
		<property name="supportFiles" value="XLSX_SXSSF_POI"/>
	</property>
		<property name="repotingEngine" class="org.iplass.mtp.impl.report.JxlsReportingEngine">
		<property name="supportFiles" value="XLS_JXLS"/>
		<property name="supportFiles" value="XLSX_JXLS"/>
		<property name="supportFiles" value="XLSX_SXSSF_JXLS"/>
		<property name="supportFiles" value="PDF_JXLS"/>
	</property>
</service>
----

[[PdfConversionService]]
=== PdfConversionService
JXLS帳票のPDF（PDF_JXLS）出力で利用する、ExcelからPDFへの変換サービスです。
service-configに独立したserviceとして登録します。
実装の差し替えは、service-configのclass定義の書き換えで行うことができます（全文検索のFulltextSearchServiceにおけるLucene／Elasticsearchの切り替えと同様の構成です）。

==== インタフェース名
----
org.iplass.mtp.impl.report.converter.PdfConversionService
----

==== 実装クラス名
.Gotenbergを利用したPDF変換
----
org.iplass.mtp.impl.report.converter.GotenbergPdfConversionService
----

==== GotenbergPdfConversionServiceの設定
Gotenbergを利用したPDF変換の項目を設定します。

===== 設定項目
[cols="1,1,3", options="header"]
|===
| 項目 | 値 | 説明
| baseUrl | String | 変換サービスのエンドポイントURL。デフォルトのservice-configでは `http://localhost:3000` が設定されています。
| connectTimeoutSeconds | int | 変換サービスへの接続タイムアウト（秒）。デフォルト値は5です。
| requestTimeoutSeconds | int | 変換サービスへのリクエストタイムアウト（秒）。デフォルト値は60です。帳票のページ数・画像の量に応じて調整してください。
| maxRetries | int | 変換サービスへのリクエスト失敗時のリトライ回数。デフォルト値は0です。
| retryIntervalMillis | long | リトライ実行時のリトライ間隔（ミリ秒）。デフォルト値は1000です。
|===

===== 設定例
[source,xml]
----
<service>
	<interface>org.iplass.mtp.impl.report.converter.PdfConversionService</interface>
	<class>org.iplass.mtp.impl.report.converter.GotenbergPdfConversionService</class>
	<property name="baseUrl" value="http://localhost:3000"/>
	<property name="connectTimeoutSeconds" value="5"/>
	<property name="requestTimeoutSeconds" value="60"/>
	<property name="maxRetries" value="0"/>
	<property name="retryIntervalMillis" value="1000"/>
</service>
----
